# The resource representation

Schema `typed_resource_v13_pooled_terms`. Generated by `scripts/write_representation.py`: every declaration and every number is
read out of the decoder, so this reports the build rather than describing it.

## 1. The object

A routing variant is a finite set of **resources**. A resource is a row
$\rho$ carrying a state, together with a finite multiset of **terms** that
say how the state moves:

$$\rho = \bigl(\mathcal X,\; x^{0},\; (\oplus,\otimes),\; T,\; \mathcal B\bigr)$$

with $\mathcal X\subseteq\mathbb R^{d}$ the state space, $x^{0}$ its initial
value, $(\oplus,\otimes)$ the semiring the update runs in, $T$ the terms, and
$\mathcal B$ the admissibility predicate.

A term is a point in seven coordinates:

$$\tau = (\sigma,\; \pi,\; \omega,\; \varphi,\; \theta,\; \gamma,\; c)$$

| | | |
|---|---|---|
| $\sigma$ | source | $\{\text{const},\ \text{node},\ \text{edge},\ d\}$ |
| $\pi$ | read point | $\{u,\ v\}$ |
| $\omega$ | operation | $\{\text{add},\ \text{join},\ \text{assign},\ \text{ckpt},\ \text{restore}\}$ |
| $\varphi$ | phase | $\{\text{before},\ \text{after}\}$ relative to the test |
| $\theta$ | trigger | $\{\top,\ \text{reset}^{\downarrow},\ \text{reset}^{\uparrow},\ \text{ckpt}^{\uparrow},\ \text{fail}\}$ |
| $\gamma$ | gate | a predicate over the unserved set |
| $c$ | coefficient | $\mathbb R$ |

The value a term contributes on the transition $u\to v$ is

$$\operatorname{val}_\tau(u,v) \;=\; c\cdot a_\tau\bigl(\pi(u,v)\bigr),\qquad \pi(u,v)=\begin{cases}v & \pi=v\\ u & \pi=u\end{cases}$$

and the operation applies it to the running state:

$$\text{add}: x \mapsto x + \operatorname{val},\qquad\text{join}: x \mapsto x \oplus \operatorname{val},\qquad\text{assign}: x \mapsto \operatorname{val}$$

$$\text{ckpt}: \bar x \mapsto x, \qquad \text{restore}: x \mapsto \bar x$$

## 2. The transition

Terms are dispatched to a fixed schedule of stages selected by their own
coordinates, not composed in the order they were written. Write
$\Omega_{P}$ for the stage selecting the terms that satisfy $P$ and
combining them by an order-free operation: a sum for additions, the
semiring fold for joins, the unique applicable term for an overwrite.
A transition is

$$T_\rho(x,u,v)\;=\;\Omega_{\theta=\text{reset}^{\uparrow}}\;\circ\;\Omega_{\varphi=\text{after}}\;\circ\;\Omega_{\varphi=\text{before}}\;\circ\;\Omega_{\theta=\text{reset}^{\downarrow}}\;(x)$$

with the admissibility test interposed between the two accumulation
points:

$$A_\rho(x,u,v) \;=\; \mathbb 1\Bigl[\Omega_{\varphi=\text{before}}\circ\Omega_{\theta=\text{reset}^{\downarrow}}(x)\;\in\;[\ell_v,\,u_v]\Bigr] \quad\text{when }\chi\text{ fires at }v$$

The transition therefore depends on $T$ only as a multiset. Sums and
semiring folds commute; two overwriting terms whose selectors can fire on
the same transition are rejected at parse time unless complementary gates
make them mutually exclusive. Term order carries no semantics, which is
why the encoding below may pool over terms without discarding any.

There are two accumulation points and two overwrite points, and the
symmetry is the reason the coordinates are $(\omega,\varphi,\theta)$ rather
than a single stage enum: $\text{reset}^{\downarrow}$ is an overwrite on
*departure*, so it can read the node the route is opening toward, which no
arrival-side reset can see.

A gate suppresses a term by a predicate over the unserved set $U$:

$$\gamma_{\text{default}}(U) = \exists j\in U:\ \operatorname{sgn} g_j = s,\qquad \gamma_{\text{alt}}(U) = \neg\gamma_{\text{default}}(U)\ \wedge\ \exists j\in U:\ \operatorname{sgn} g_j = -s$$

**Composition.** A variant with rows $R$ has product state
$X=\prod_{r\in R}\mathcal X_r$, transitions componentwise, and
$A=\bigwedge_{r\in R}A_r$. Each $x_r$ is a sufficient statistic for its own
row's continuation feasibility, so $X$ is sufficient for the conjunction.

## 3. The encoding the network reads

Two maps into fixed-width real vectors, one per row and one per term:

$$\Phi_{\text{row}}:\rho\mapsto\mathbb R^{14},\qquad \Phi_{\text{term}}:\tau\mapsto\mathbb R^{20}$$

A row is then encoded by pooling its terms, so the width does not depend on
how many terms it has:

$$h_\rho \;=\; \psi\Bigl(\Phi_{\text{row}}(\rho),\;\tfrac{1}{|T|}\textstyle\sum_{\tau\in T}\phi\bigl(\Phi_{\text{term}}(\tau)\bigr),\;|T|\Bigr)$$

The sum is permutation-invariant and $|T|$ is carried explicitly, so adding a
term moves $\rho$ to a new point without changing any tensor width.

$\varsigma(z)=z/(1+z)$ below, and $\operatorname{sgn}^+(z)$ is the three-valued sign: $1$ for $z>0$, $0$ for $z<0$, $\tfrac12$ for $z=0$, so an absent quantity sits between the two signs rather than sharing a value with one.

**$\Phi_{\text{row}}$**

| $i$ | coordinate | reading |
|---|---|---|
| 0 | $\mathbb 1[\text{extension function}]$ | carries state, versus constraining service order |
| 1 | $\mathbb 1[\text{pairwise}]$ | relation form; class order is the complement |
| 2 | $\mathbb 1[\ell > -\infty]$ | lower bound finite |
| 3 | $\mathbb 1[u < \infty]$ | upper bound finite |
| 4 | $\mathbb 1[\ell\text{ or }u\text{ varies by node}]$ | per-node bound |
| 5 | $\mathbb 1[\chi = \text{transition}]$ | check phase, ordinal with slot 6 |
| 6 | $\mathbb 1[\chi \neq \text{solution end}]$ | $(1,1)\prec(0,1)\prec(0,0)$ |
| 7 | $\mathbb 1[s = \text{route}]$ | resets at the depot; solution scope is the complement |
| 8 | $\mathbb 1[\text{horizon} = \text{return}]$ | bound projected across the return leg |
| 9 | $\mathbb 1[\text{horizon} = \text{return}^{c}]$ | that projection is construction-only |
| 10 | $\varsigma(d_r)$ | state width, squashed |
| 11 | $\varsigma(|x^0|/\text{scale})$ | initial magnitude |
| 12 | $\operatorname{sgn}^+(x^0)$ | initial sign, kept off the magnitude axis |
| 13 | $|{\sim}|/n$ | declared-relation density |

**$\Phi_{\text{term}}$**

| $i$ | coordinate | reading |
|---|---|---|
| 0 | $\mathbb 1[\sigma = \text{node}]$ | reads a node attribute |
| 1 | $\mathbb 1[\sigma \in \{\text{edge},d\}]$ | reads the pair |
| 2 | $\mathbb 1[\sigma = d]$ | is the intrinsic metric (a constant reads none) |
| 3 | $\mathbb 1[\pi = u]$ | reads the origin rather than the destination |
| 4 | $\mathbb 1[\omega\text{ linear}]$ | $x \mapsto x + c\,a$ |
| 5 | $\mathbb 1[\omega\text{ absorbing}]$ | discards the incoming state |
| 6 | $\mathbb 1[\omega\text{ idempotent}]$ | $\omega\circ\omega = \omega$ |
| 7 | $\mathbb 1[\omega\text{ shadow}]$ | acts on the saved copy, not the live value |
| 8 | $\tfrac12(1 + \operatorname{or}(\vee))$ | join orientation: $\min\!\to\!0$, none $\to\tfrac12$, $\max\!\to\!1$ |
| 9 | $\mathbb 1[\varphi = \text{after}]$ | acts after the admissibility test |
| 10 | $\mathbb 1[\theta \neq \text{always}]$ | conditional |
| 11 | $\mathbb 1[\theta = \text{fail}]$ | failure-driven |
| 12 | $\mathbb 1[\theta = \text{reset}^{\downarrow}]$ | departure-side |
| 13 | $\mathbb 1[\text{locus} = \text{depot}]$ | fires at any depot |
| 14 | $\mathbb 1[\text{locus} = \text{nodes}]$ | fires at declared nodes |
| 15 | $\mathbb 1[\gamma \neq \top]$ | gated by the unserved remainder |
| 16 | $\text{polarity}(\gamma)$ | which side of the remainder the gate selects |
| 17 | $\operatorname{sgn}^+(g)$ | gate attribute sign |
| 18 | $\varsigma(\overline{|c\,a|}/\text{scale})$ | mean coefficient magnitude over the declared values |
| 19 | $\operatorname{sgn}^+(c)$ | coefficient sign, kept off the magnitude axis |

Every coordinate is a property, not a membership test. An operation is
located by linearity, absorption, idempotence and whether it touches the
shadow copy, so a further operation is a point in those four rather than a
new axis; the check phase and the join orientation are ordinals, so a new
value falls *between* existing ones.

## 7. Coverage of the encoding

- $\Phi_{\text{row}}$: 14 axes, 8 distinct images over 110 variants, $\operatorname{rank} = 7$
  - constant on this family: $6$ (no solution-end check occurs); $9$ (no construction-only horizon occurs); $10$ (every row is scalar, $d_r = 1$)
- $\Phi_{\text{term}}$: 20 axes, 40 distinct images over 110 variants, $\operatorname{rank} = 10$
  - constant on this family: $3$ (no term reads the origin, $\pi = v$ throughout); $7$ (no checkpoint or restore); $11$ (no failure-driven trigger); $14$ (no event reset at declared nodes)

The gap between the axis count and the rank is deliberate: the surplus axes
are what make a new declaration a **point** in this space rather than a change
of tensor width. A constant axis is a different matter. Its weights receive no
gradient, so a resource that first exercises one is reading an untrained
direction, and the transfer claim for such a resource is correspondingly
weaker. Those axes are what a randomized training program has to cover.
